```text
What I’ve learned about studying AI & Data Science as an undergraduate:

The biggest gap isn't understanding how a loss function works in theory — it's taking a model and turning it into a dependable, usable product.

Three principles I've embraced while building projects:
1. Don't stop at model training: Build the API (FastAPI) and the interface (React/Streamlit) so people can actually use it.
2. Data quality > model complexity: 100K cleaned images with robust preprocessing will always outperform an overparameterized model trained on noisy inputs.
3. Keep learning adjacent tools: Docker, FAISS, and modern vector databases are just as critical as PyTorch.

Looking forward to continuing to build in this space.
```
